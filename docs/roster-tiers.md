# Internship Pipeline — Tiered Firm Roster (DRAFT for review)

> **Axis: prestige / selectivity** (not public fame). Tier = how elite/selective/desirable
> the firm is *within its domain*. Admission bar to appear at all = respectable in-domain prestige.
>
> - **T1 — elite:** the top bucket in the domain; most selective, most desirable.
> - **T2 — strong:** clearly respected, one notch below the apex.
> - **T3 — solid:** real in-domain prestige, smaller / more specialized / less broadly known.
>
> **Feed note:** ⛔ = no keyless machine feed (custom / HireVue / locked portal) → these route to the
> LLM **discovery** path (Path B), everyone else to the deterministic **ATS** path (Path A).
> Feed marks are only on the obvious no-feed marquees; the rest get auto-detected by `verify_tokens.py`.
>
> Built from domain knowledge (cutoff Jan 2026). The **T3 long tail is where this is most likely
> incomplete** — flag gaps and I'll extend. Everything here is a starting point to correct, not a verdict.

> **Scope decisions (locked 2026-07-13):**
> - **US-only.** No London / Europe / Asia coverage.
> - **Asset Management dropped** (not a prestige-internship hunt).
> - **Corporate Strategy is its own domain** = any large US company with a corporate strategy /
>   BizOps / corp-dev program (not just tech).
> - **T3 built deep** — target hundreds of firms total: any firm that is boutique/lesser-known
>   but still holds real in-domain prestige belongs on the list. Requires a deep-research pass.
